# BookOn

BookOn is a comprehensive Android application designed for book enthusiasts. It allows users to discover new books, organize their reading life with custom shelves, and engage with a community of fellow readers.

## Features

- **Book Discovery**: Search the extensive Google Books database by title, author, or ISBN.
- **Personalized Shelves**: Create and manage collections like "To Read", "Currently Reading", and "Favorites".
- **Community Hub**: Share your reading progress, thoughts, and book recommendations through posts.
- **In-depth Reviews**: Write and read detailed reviews and ratings for any book.
- **Account Customization**: Personalize your profile and track your reading journey.

## Getting Started

### Prerequisites
- Android Studio Jellyfish or newer.
- Android SDK 34+.
- A Google Cloud API Key for Google Books API.

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/BookOn-App.git
   ```
2. **Setup API Key**:
   - Add your API key: `Book Respository file`.
3. **Build and Run**: Open the project in Android Studio and run it on an emulator or physical device.

## How to Use

### 1. Authentication
- **Register**: New users can create an account via the Register screen to start building their library.
- **Login**: Existing users can sign in to sync their shelves and participate in the community.

### 2. Browsing Books
- From the **Home** or **Browse** screen, use the search bar to find books.
- Tap on a book card to view its **Detail Page**, which includes the description, author info, and community ratings.

### 3. Managing Your Shelves
- Navigate to **My Shelves** from the main menu to see your collections.
- Add books to specific shelves directly from the Book Detail page by clicking "Add to Shelf".
- Organize your reading by creating custom shelf names.

### 4. Community Interaction
- Visit the **Community** tab to see the global feed of posts from other readers.
- Use the **Create Post** button to share your latest read, images, or updates.
- **Write Reviews**: Share your opinion on a book by tapping 'Write Review' on its detail page.
